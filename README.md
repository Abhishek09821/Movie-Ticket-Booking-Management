**Movie Ticket Management Application**

A Pega Platform application built for the National Internship Program (NIP) 2026 to manage movie ticket booking from request creation to confirmation.

**Features** : 
1. Movie ticket request with movie name, show date, show time, and ticket quantity.
2. Show availability and seat management.
3. Automatic booking cost calculation.
4. Booking approval workflow.
5. Ticket ID and seat number allocation.
6. Booking confirmation email notification.
7. SLA with 1-day goal and 2-day deadline.
8. Show-type based work queue routing.


**Tech Stack** : Pega Platform · Pega App Studio · Pega Dev Studio

**Case Flow** : Initial Request → Availability → Approval → Booking Execution → Resolved
